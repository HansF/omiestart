# omiestart

A simple, large-print start page for mum. Hosted with GitHub Pages.

Edit the `LINKS` list in `index.html` to change the buttons.

Sudoku is adapted from [EleftheriaBatsou/sudoku](https://github.com/EleftheriaBatsou/sudoku), with six difficulty settings (targeting 46, 40, 36, 32, 28, or 26 clues); easy is the default. Clues are only removed when the solution remains unique, so the final clue count can be higher. These are clue-count settings, not formal logical difficulty ratings. Local changes include Dutch controls, automatic start, larger controls, and input/completion fixes.

The upstream README grants permission: “You can use, modify, and distribute this project in your own apps or portfolios.” Source files are in `sudoku/`; the entry page is `sudoku.html`.
